Desde la raíz del proyecto, ejecuta los siguientes comandos para iniciar Feature Sprint.

**Commands**

npx json-server db.json

npm install

npm run dev 	->	En el primer terminal




Uso db.json como backend con JSON Server. La documentación oficial permite levantar una API REST directamente a partir de un db.json.

npm install --save-dev json-server




npm run server 	->	 En el segundo terminal (Este comando va a funcionar debido al db.json)
